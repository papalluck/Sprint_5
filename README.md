# Sprint_5
TestRegistration: Проверяет успешную регистрацию пользователя и проверяет, что отображается сообщение об ошибке
при вводе некорректного пароля.
TestLogInToYourAccount: Проверяет вход на сайт с главной страницы, проверяет вход на сайт через личный кабинет,
проверяет вход на сайт из формы регистрации, проверяет вход на сайт из формы восстановления пароля.
TestTransferToYourPersonalAccount: Проверяет переход в личный кабинет, проверяет переход в конструктор из личного
кабинета по клику на ссылку “Конструктор”, проверяет переход в конструктор из личного кабинета по клику на логотип.
TestLogOutOfYourAccount: Проверяет выход из аккаунта.
TestSelectingSection: Проверяет переходы к разделам “Булки”, “Соусы” и “Начинки” в конструкторе.
