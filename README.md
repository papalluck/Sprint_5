# Sprint_5
test_successful_registration: Проверяет успешную регистрацию пользователя.
test_registration_incorrect_password: Проверяет, что отображается сообщение об ошибке при вводе некорректного пароля.
test_login_from_main_page: Проверяет вход на сайт с главной страницы.
test_login_from_profile: Проверяет вход на сайт через личный кабинет.
test_login_from_register_form: Проверяет вход на сайт из формы регистрации.
test_login_from_reset_password_form: Проверяет вход на сайт из формы восстановления пароля.
test_go_to_profile: Проверяет переход в личный кабинет.
test_go_to_constructor_from_profile: Проверяет переход в конструктор из личного кабинета по клику на ссылку “Конструктор”.
test_go_to_constructor_from_profile_logo: Проверяет переход в конструктор из личного кабинета по клику на логотип.
test_logout: Проверяет выход из аккаунта.
test_click_bun, test_click_sauce, test_click_filling: Проверяют переходы к разделам “Булки”, “Соусы” и “Начинки” в конструкторе.
